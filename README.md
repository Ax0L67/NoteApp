# NoteApp

Локальное настольное приложение для личных заметок. Интерфейс на русском, обычные Markdown-файлы, без регистрации и внешнего сервера. Дизайн основан на выбранном графитово-лавандовом макете с мягкими панелями в духе iOS 17.

## Запуск

Нужны **Node.js 22.12+**, npm, стабильный Rust и системные зависимости Tauri:

- Windows: Microsoft C++ Build Tools (Desktop development with C++), Windows SDK и WebView2.
- macOS: Xcode Command Line Tools.
- Linux: WebKitGTK 4.1, GTK 3, системный компилятор; точный список для дистрибутива — в [инструкции Tauri](https://v2.tauri.app/start/prerequisites/).

В терминале из папки проекта:

```sh
npm ci
npm run desktop
```

При первом запуске создаётся `Документы/NoteApp`. Кнопка имени хранилища в левом верхнем углу и настройки позволяют выбрать другую папку. Пустое хранилище не заполняется демонстрационными файлами без вашего действия. Кнопка «Открыть пример Markdown» создаёт пример.

Для просмотра интерфейса в браузере:

```sh
npm run dev
```

Откройте `http://127.0.0.1:1420`. **Браузерный предпросмотр хранит демонстрационные данные в localStorage и не заменяет настольное приложение.** Выбор папки, импорт и резервное копирование требуют настольной версии. Предпросмотр и настольная версия не разделяют данные.

## Сборка

```sh
npm run build
npm run bundle
```

Установочные пакеты: `src-tauri/target/release/bundle/`. Сборку каждой ОС следует выполнять на соответствующей ОС. Подпись установщиков и notarization не настроены: для распространения их нужно добавить отдельно.

Сборка отладочного исполняемого файла без установщика:

```sh
npx tauri build --debug --no-bundle
```

На Windows результат: `src-tauri/target/debug/noteapp.exe`.

## Архитектура

Выбран **Tauri 2 + Rust + React/TypeScript + CodeMirror 6**. Tauri использует системный WebView вместо поставки Chromium. Rust отвечает за файловые операции, React — за интерфейс. Подробности архитектуры Tauri: [официальная документация](https://v2.tauri.app/start/).

```text
crates/vault/src/lib.rs    независимое файловое ядро и тесты
src-tauri/src/main.rs     команды Tauri, диалоги, выбор хранилища
src/storage.ts           адаптер IPC и отдельный браузерный предпросмотр
src/indexing.ts          заголовки, теги, внутренние/обратные ссылки
src/search.ts            полнотекстовый поиск и фрагменты совпадений
src/Editor.tsx           CodeMirror, чтение Markdown, локальные изображения
src/App.tsx              интерфейс, черновики, навигация, диалоги
src/styles.css           темы, палитры, размеры панелей
src/templates.ts         встроенные шаблоны
public/wallpaper.png     локальный фон; интернет не нужен
```

Markdown-файлы — источник истины. Индекс полностью строится из прочитанных файлов; никакой обязательной базы данных нет. IPC принимает ограниченный набор операций, пути внутри хранилища проверяются, переходы `..` и символические ссылки отвергаются. Второй процесс не может открыть то же хранилище для записи.

## Данные хранилища

```text
Моя заметка.md
Знания/Другая заметка.md
attachments/              вложения и пользовательские фоны
.noteapp/settings.json    тема, фон, избранное, последние заметки, размеры
.noteapp/templates/*.md   пользовательские шаблоны
.noteapp/trash/           удалённые заметки и их исходные пути
.noteapp/transaction.json журнал незавершённого переименования (временно)
.noteapp/lock             блокировка второго экземпляра
```

Сохранение: временный файл в той же папке → запись → `sync_all` → атомарная замена. Перед заменой сравнивается SHA-256 исходного содержимого. Изменения внешнего редактора проверяются также опросом каждые 3,5 секунды. Несохранённый текст немедленно записывается в аварийный черновик WebView и восстанавливается при старте. При обычном закрытии приложение ожидает завершения сохранения.

При конфликте доступны: версия с диска, ваша версия с явной перезаписью, либо сохранение обеих. Восстановление из корзины не перезаписывает существующую одноимённую заметку. Переименование нескольких файлов журналируется; после сбоя операция завершается при открытии, если файлы не были дополнительно изменены снаружи. При несовместимом внешнем изменении журнал сохраняется, приложение сообщает о конфликте вместо перезаписи.

## Возможности

- Создание, редактирование, переименование/перемещение и удаление заметок; папки, избранное, недавние, корзина с восстановлением.
- Автосохранение через 450 мс после ввода и видимый статус; восстановление аварийного черновика.
- Markdown: заголовки, списки, задачи, цитаты, ссылки, таблицы GFM, код и локальные изображения; отдельное чтение.
- Вставка изображений из буфера и перетаскивание файлов; вложения в `attachments/`, относительные Markdown-ссылки.
- `[[Название]]`, `[[Папка/Название]]`, псевдонимы `[[Название|подпись]]`; подсказки при вводе `[[`; переходы в режиме чтения и создание отсутствующей заметки.
- Обратные ссылки, оглавление, теги `#тег`, фильтрация; обновление wiki-ссылок при переименовании.
- Поиск по всем названиям и тексту, подсветка совпадения и фрагмент; история назад/вперёд.
- Четыре встроенных шаблона, редактор собственных шаблонов, `{{title}}`, `{{date}}`, ежедневная заметка.
- Светлая/тёмная темы, пять палитр, собственное фоновое изображение, размер шрифта и ширина текста отдельно для каждого хранилища.
- Изменение ширины боковых панелей мышью или стрелками при фокусе на разделителе; скрытие панелей и режим фокуса.
- Импорт папки с вложениями в отдельную подпапку без перезаписи; экспорт/резервное копирование полной папки, включая настройки и корзину. Восстановление — открытие копии как хранилища либо импорт её заметок.

## Проверки

```sh
npm test
cargo test --manifest-path crates/vault/Cargo.toml
npm run build
```

Тесты ядра проверяют сохранение/повторное открытие, внешние конфликты, блокировку второго процесса, безопасные пути, переименование ссылок, относительные вложения при перемещении, корзину без перезаписи, копирование вложений и восстановление прерванной операции. Тесты TypeScript проверяют поиск, обратные ссылки, теги и оглавление. Результаты ручной проверки и ограничения среды записаны в `TESTING.md`.

## Ограничения первой версии

- Полный индекс находится в памяти, файлы опрашиваются периодически; большие хранилища с десятками тысяч заметок не профилировались.
- Импорт/экспорт и резервные копии используют папки, а не ZIP. Нет автоматического расписания копирования и истории каждой версии.
- Вложения ограничены 20 МБ при добавлении. Изображения: PNG, JPEG, WebP, GIF, AVIF. Внешние изображения не загружаются автоматически; HTML внутри Markdown не исполняется.
- Для одинаковых названий в разных папках используйте квалифицированные ссылки `[[Папка/Название]]`. Неоднозначные короткие ссылки не переписываются при переименовании.
- Оглавление и индекс wiki-ссылок используют простой разбор текста; конструкции внутри блоков кода могут попадать в индекс. Ссылка с `#разделом` открывает заметку, но не прокручивает к указанному разделу.
- Автоматически обновляются wiki-ссылки `[[...]]`; обычные Markdown-ссылки на переименованную заметку из других файлов не переписываются. Относительные ссылки внутри перемещаемой заметки корректируются.
- Блокировки защищают от второго экземпляра NoteApp, но не блокируют произвольные внешние редакторы. Между проверкой хеша и атомарной заменой остаётся небольшое окно конкурентного доступа; совместную одновременную запись другими программами следует избегать.
- Без облачной синхронизации, совместного редактирования, плагинов, ИИ и графа связей.
- Windows — текущая среда проверки. macOS/Linux требуют сборки и проверки на соответствующих системах; готовые подписанные пакеты для них не заявляются.
